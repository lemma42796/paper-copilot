# Query 1 aligned rubric v1

状态：冻结
版本：`query1-aligned-v1`
冻结日期：2026-08-03
适用范围：`multi-thesis-v1` 的冻结 Query 1

## 评分目标

本评分只衡量 Query 1 明确要求的主任务：覆盖全部 14 篇论文，并逐篇给出题目、作者、
唯一主要类别、监督设定、所涉及的模态和支持判断的 PDF 页码。具体方法名称、机制细节和
次要主题只做诊断；缺少这些可选细节不扣主任务分。

## 原子字段与主分

每篇论文有 6 个等权字段：

1. `title`
2. `author`
3. `main_category`
4. `supervision`
5. `modalities`
6. `evidence_pages`

共 `14 × 6 = 84` 个原子项。每项使用同一四级判定：

| 判定 | 分值 | 含义 |
|---|---:|---|
| `correct` | 1 | 与论文证据一致，语义完整到足以完成该字段 |
| `partial` | 0.5 | 核心方向正确，但存在影响完整性的省略、含混或轻微冲突 |
| `incorrect` | 0 | 给出了可判定但与证据冲突的值 |
| `missing` | 0 | 未提供、明确弃答，或无法归属于该论文 |

主要报告：

- strict：`correct / 84`
- weighted：`(correct + 0.5 × partial) / 84`
- completion：`(correct + partial + incorrect) / 84`
- paper coverage：被唯一识别并进入评分的论文数 `/ 14`

`incorrect` 与 `missing` 分值相同，但必须分开报告。不得将调用数、token、费用、耗时、
工具失败或恢复并入主分。

## 字段边界

### 题目与作者

- 题目完整或只有标点、空格等不改变身份的差异为 `correct`；无歧义但明显缩写为
  `partial`；指向另一篇或无法识别为 `incorrect`。
- 作者准确为 `correct`；不影响唯一识别的单字笔误为 `partial`；错配作者为
  `incorrect`。
- 同一篇出现多行时只计一次；使用最终且最完整的一行。重复行不增加分数，并进入格式
  约束诊断。

### 唯一主要类别

- 与论文的整体主要研究问题语义等价为 `correct`，不要求复述具体方法名。
- 只给出过宽上位类、遗漏区分该论文的核心问题，或同时列出多个未裁决的主要类别，为
  `partial`。
- 把组件、次要主题或另一篇论文的问题当作整体主要类别，为 `incorrect`。
- 显式标注的“主要类别”优先于解释性文字；若同一单元格保留相互冲突的未决标签，最高
  为 `partial`。

### 监督设定

- 正确区分有监督、混合监督与无监督、无监督域适应、完全无监督，为 `correct`。
- P12 只写“无监督”而未体现有标签源域到无标签目标域的域适应，为 `partial`；误写为
  完全无监督为 `incorrect`。
- P03 只写有监督或只写无监督为 `partial`；写成纯完全无监督为 `incorrect`。
- P07 的噪声标签是可选细节；写“有监督”已经满足主字段，未写噪声标签不扣分。

### 模态

- 报告所有决定性模态，允许 RGB/可见光、IR/红外及文本等语义等价写法。
- 仅遗漏一个决定性模态、把近红外与热红外合称为有明确含义的“红外”，或包含一个不改变
  核心设定的轻微多余项，为 `partial`。
- 遗漏一半以上决定性模态、把数据集/训练标签当模态，或核心模态冲突，为 `incorrect`。
- 相机 ID、时空轨迹等作为论文实际输入信息时按模态/输入源处理，不因其不是图像而忽略。

### 判断页码

- 至少一个明确 PDF 页码经原文核验能直接支持该行的主要类别或核心输入/监督判断，为
  `correct`；可以使用冻结参考页以外的真实支持页。
- 只给印刷页码且未标明与 PDF 页码的映射、给出过宽范围但其中包含支持页，或页码只支持
  次要细节而不能支持该行主要判断，为 `partial`。
- 给出页码但核验后均不支持、页码不存在或使用网页链接代替，为 `incorrect`；没有页码为
  `missing`。
- 页码字段只评价定位与支持关系，不因未逐字段分别给页码重复扣分。

## 约束诊断

以下单独报告，不改变 84 项主分：

- 是否覆盖 14 篇；
- 每篇是否只有一个主要类别；
- 若提供次要主题，是否与主要类别分开；
- 是否保持每篇一行及紧凑表格；
- 回答中是否出现网络来源、URL 或外部材料归因；
- 有效 PDF 页码能否证明答案不是只依据文件名。

“是否实际调用网络”和“读取路径是否只看文件名”只能在揭盲后由权威 trace 验证；盲评
阶段不得根据文风猜测。运行合规状态与回答质量分开保存。

## 可选细节诊断

方法名、机制、数据集、结果数字和次要主题不属于主分。遗漏不扣分；若主动提供，则记录
`supported / partial / unsupported`，并单独统计错误陈述，不回写主任务 84 项得分。

## 冲突裁决

- 以最终表格或明确的最终自我修正为准；未解决的相互冲突最高为 `partial`。
- “未确认”按 `missing`，不能因谨慎措辞自动获得 `partial`。
- 一行错配到另一论文时按每个字段实际内容逐项判定，不整体连坐，也不重复计入另一篇。
- 不按措辞相似度打分；只按冻结语义边界和论文证据。
- 评分期间只显示匿名答案及本 rubric，不显示系统、Runtime、工具调用、token、费用、
  历史分数或身份映射。全部 scorecard 锁定后才揭盲。
