# Formula OCR 主动定位验证提示词

更新于 2026-08-12。

## 使用边界

本提示词用于验证主动坐标探索式公式 OCR，并保留为后续回归的冻结输入。该提示词已经用于
真实定位与识别；后续 v4 验收另行完成了 `accept`、overlay 页面回读和新会话零 OCR 复用。

提示词本身保持为自然的论文核对请求，不向执行模型说明评测目的、预期页码、正确公式
结构或判定标准，避免把待验证结论泄露给被测流程。首轮只执行 `recognize`，不调用
`accept`，以免未经人工复核的 OCR 结果写入缓存。

选择的三个目标分别覆盖：有编号且含乱码的公式、没有编号且只能依靠语义上下文定位的
行内公式，以及文本层可能静默丢失结构的复杂分段公式：

- 项莘泽（2025）公式 (2-9)；
- 彭思懿（2025）CMC 示例中的无编号 Rank-3 计算式；
- 何子玲（2023）公式 (4.10)。

## 发送给 Paper Copilot 的提示词

```text
我在核对几篇论文中的数学表达式，请从原 PDF 中找到下面三个公式，准确转写为 LaTeX，并结合上下文简要解释各符号及公式作用。

1. 《基于多模态信息融合的行人轨迹追踪方法研究》（项莘泽，2025）中的公式 (2-9)。

2. 《基于多粒度特征融合的多模态行人重识别研究》（彭思懿，2025）中介绍 CMC 曲线时，“共有 5 个查询图片”那个例子里的 Rank-3 计算式。这个表达式没有单独的公式编号，请根据上下文找到它。

3. 《基于低秩融合与动态增强的多模态行人重识别研究》（何子玲，2023）中的公式 (4.10)。

缓存中的公式文本可能不完整。为了确保数学符号、上下标、根号、分段结构和运算符准确，请在确有必要时从原 PDF 裁剪公式并识别。你可以根据识别结果调整裁剪范围，但同一公式不要超过三次。

暂时不要把识别结果写回缓存，也不要替换原有内容。请先把结果交给我确认。

为了便于我复核，请在最终回答末尾附上简短的“原文定位记录”。针对每个公式列出：

- 论文和公式标识；
- 找到的物理页；
- 实际采用的定位依据；
- 每次裁剪使用的归一化 region；
- 每次识别得到的原始 LaTeX；
- candidate_id 和 render_sha256；
- 是否调整过裁剪范围及原因；
- 最终仍不确定的字符或结构。

如果执行过程中能够保留裁剪图片，请同时给出图片或产物路径；如果不能，则保存每次裁剪的 region 和 render_sha256 即可。

正文只需要准确转写和简要解释，不要展开成长篇论文分析。
```

## 结果复核边界

当前 `recognize_formula` 会把裁剪 PNG 放入临时目录，并在 Helper 调用结束后删除；持久化
证据是工具结果和 trace 中的 `region`、`candidate_id`、`render_sha256` 与原始 LaTeX，
不是裁剪图片。执行模型不得声称未返回路径的图片已经保存。若以后产品需要人工逐图审计，
应单独设计受控的裁剪图产物持久化机制，不能靠提示词保证。

收到首轮结果后，先人工核对定位、裁剪边界和原始 LaTeX，再决定是否执行 `accept`。
`accept` 不替换 `layout.txt`：Runtime 重新验证 PDF 哈希，将页码、明确 `region`、
`formula_ref`、LaTeX、模型与证据哈希写入新 revision 的 `formulas.jsonl`，随后原子发布
`current`。验收应确认原 `layout.txt` 哈希保持不变，页面读取和搜索只把已接受公式作为
`verified=false` 的独立 overlay 附加，并在新会话中无需再次 OCR 即可复用。
